# LightTerm Changelog

## v0.1.2

发布时间：2026-04-22

### 终端体验

- 修复 Codex/CLI 场景下的光标回退、覆盖刷新、清行和多屏滚动问题，减少 `Working...` 等动态输出被重复堆叠。
- 会话页改为默认终端直接输入，命令栏改为手动展开，更贴近移动端 SSH 客户端常见交互。
- 命令栏新增上下文补全，支持常用命令、子命令、参数、最近远端路径、命令历史和命令模板建议。
- 连接后会尝试将首屏 prompt 简化为 `$ `，避免默认展示 `user@host:path$`。
- 终端字体下限继续下调，可选择更小字号。

### 文件管理与历史能力

- 修正远端文件管理中的上传图标，与下载图标区分开。
- 文件列表默认排序方式改为按修改时间倒序。
- 最近打开的远端目录和文件现在会持久化，重启应用后仍可恢复。

### 命令模板与历史搜索

- 新增命令模板仓库、命令历史仓库和对应弹层 UI。
- 修复命令模板点击使用闪退问题。
- 删除旧的 `codexinline` 功能与相关默认模板。
- 历史搜索支持命令历史检索与终端输出跳转。

### 输入法与移动端兼容性

- 调整终端输入连接参数，改善中文输入法、语音转文字和候选栏兼容性。
- 会话页顶部状态信息收缩，仅保留标签页状态点，让终端获得更大可视区域。

### 测试与工程

- 为终端模拟器、命令模板解析、命令补全和 SSH prompt 初始化补充单元测试。
- 文档同步更新，补充本次变更说明与发布流程。
